# 阅读 LaOS

英文版本：[Reading LaOS](README.md)。

本书沿当前 x86_64 实现说明从启动到用户任务运行的过程。章节顺序与 ARM64 叙述文档一致，但正文以本检出目录中的代码为依据；ARM64 实现及其分支专属内容保留在 `arm64` 分支。

book 说明子系统之间的关系，design 提供专题教程和实现约束。构建环境见 [入门指南](../getting-started.md)，能力评估以 [当前限制](../current-limitations.md)为准。

| 章节 | 内容 |
| --- | --- |
| [1. 启动](01-boot-zh.md) | 从引导程序提供的状态建立内核运行环境 |
| [2. 内存](02-memory-zh.md) | 物理页、映射与虚拟区间的所有权 |
| [3. 中断](03-interrupt-zh.md) | 保存并恢复被中断的执行上下文 |
| [4. 调度](04-scheduler-zh.md) | 选择下一可运行线程 |
| [5. 用户态](05-user-mode-zh.md) | 用户程序进入和离开内核的过程 |
| [6. 设备](06-devices-zh.md) | 设备发现、DMA 与存储路径 |
| [7. 同步](07-synchronization-zh.md) | 执行顺序与对象生命周期保证 |
| [8. 移植](08-porting-zh.md) | 新架构需要满足的接口约束 |
| [9. 源码与测试串讲](09-walkthrough-zh.md) | 通过源码、配置和日志解释一次执行 |

所有命令均从仓库根目录执行。练习采用源码分析或现有测试目标；除明确标注为日志标志的内容外，流程示意不表示实际串口输出。测试通过所能证明的范围取决于目标中的具体断言。
